Key:
A rule must declare its trace - the observable that shows the rule was kept or broken. It may name an enforcer, the tool that checks it, when one exists; a practice has no trace to declare.

Rubric:
2 for the required trace and the optional enforcer. 1 for the trace alone. 0 otherwise.

--- answer a-c817d890 ---
A rule must declare `trace` in its frontmatter. RU0 calls this "the observable in the record that shows it was kept or broken, required by the catalogue contract". The schema (schemas/catalog-entry/v1alpha1/catalog-entry.schema.json) requires `trace` for category `rule` with ids `RU[1-9]...`, with `minLength: 20`. A practice "declares no `trace`; if it acquires one, it is a rule and moves" (PC0). Optionally, a rule may declare `enforced-by` to name the tool that checks it. The schema's trace description says "Naming a tool that checks it is enforced-by's job, and is optional". RU0 adds "a rule with no tool yet is still a rule, and is checked by reading the trace". When `enforced-by` is present, `tools/check-enforcers.sh` checks that the tool exists.

PROBE layer-charters.H6

Question:
Give the order of questions an agent asks to decide whether a piece of guidance is an axiom, a method, a style rule, a rule or a practice.

Key:
In order, stopping at the first yes: is it in force regardless of situation (axiom); does following it produce a result of its own (method); does it govern how an artifact is written - its form, whatever the work was (style); does it leave a trace in the record of the work that a check could test (rule); otherwise practice.

Rubric:
2 for all five steps in this order with these tests. 1 for an order or tests that would still file M1 as a method, M3, M4, M5 and K2 as rules, and M6 as a practice; or four of the five steps. 0 otherwise.

--- answer a-261d4c6f ---
This comes from M0 (methods/README.md, "Placement"). Ask the questions in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? Then it is an axiom.
2. Does following it produce a result of its own (a verdict, an artifact, a record)? Then it is a procedure/method. Guidance that only *requires* a record to carry something is a rule.
3. Does it govern how an artifact is written, its form, whatever the work was? Then it is style.
4. Does it leave a trace in the record of the work that a check could test? Then it is a rule.
5. Otherwise, it is a practice.
