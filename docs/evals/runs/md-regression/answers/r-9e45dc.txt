### work-layers.L5
This is the "Handing over" moment, the sixth of the six moments M0 defines. Which layer it goes in depends on its shape: steps that produce a handover record would go in `methods/`, a requirement that the record carry something would go in `rules/`, and judgement that leaves no trace would go in `practices/`. The corpus states the absence in all three layers. ### work-layers.L6
Method: following it "produce[s] a result of its own - a verdict, an artifact, a record" (M0 placement question 2). Skill: "a capability you execute ... a procedure with inputs and outputs, invoked rather than followed" (M0 table); K0 adds that "a method is a procedure held as guidance, the single source of its content; a skill packages a procedure so an agent can install and invoke it, and earns its packaging where scripts or assets make it necessary." Work-type: "taxonomy-grade **iff it compiles to a closeable claimable node**" (W0), i.e. a kind of work with roles, domains, evidence contract and falsifier, which cites methods rather than being one. Method against skill is the hard pair, because both are procedures and the line is packaging. The corpus admits it went wrong once: M0 lists the fault "The procedure that is really a skill", and K0 says "A skill that only describes is a method ... as `M9` was before it moved" (`skills/K1-history-content-scrub.md` is now superseded by M9). Note that M0's ordered five-question test never names skills or work-types, so those two can only be separated with the M0 table, K0 and W0.
