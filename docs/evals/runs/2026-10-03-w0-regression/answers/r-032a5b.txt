Sentence case is a predicate over the text, so S0 would want it enforced by exactly one tool named in `enforced-by`.

### layer-charters.H5
A rule must declare `trace` in frontmatter: "the observable in the record that shows it was kept or broken, required by the catalogue contract" (`rules/README.md`, "Member shape").
The schema enforces this (`schemas/catalog-entry/v1alpha1/catalog-entry.schema.json`): for `category: rule` with id `RU[1-9]...`, `trace` is required, with a minimum length of 20.
A practice "declares no `trace`; if it acquires one, it is a rule and moves" (`practices/README.md`).
A rule may optionally declare `enforced-by`, which names the tool that checks it. The path must match `^tools/`, and `tools/check-enforcers.sh` checks that the tool exists.
"a rule with no tool yet is still a rule, and is checked by reading the trace" (`rules/README.md`); the schema says naming a tool "is enforced-by's job, and is optional".

### layer-charters.H6
`methods/README.md` (M0) gives this order, and `rules/README.md` and `practices/README.md` cite it. Ask in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? Then it is an axiom.
2. Does following it produce a result of its own (a verdict, an artifact, a record)? Then it is a method. Guidance that only requires a record to carry something is a rule, not a method.
3. Does it govern how an artifact is written, its form, whatever the work was? Then it is style.
4. Does it leave a trace in the record of the work that a check could test? Then it is a rule.
5. Otherwise it is a practice.

### layer-charters.H7
Taken literally, the three charters leave no whole moment without coverage. Here is what each of the six holds:
- entering: M8 and PC1
- committing to a design: M7
- verifying: M1 and M2
- deciding what to keep: RU1 and RU3
- treating the record: M9, RU2 and RU4
- handing over: M10
The ungoverned part is inside *handing over*: handing work in progress to another agent or to a later session.
M0 says that "has no procedure at all", and adds that "a lone agent hands over to its own next session".
`rules/README.md` says handing over holds no rule ("*a handover record names what is unfinished* - would leave a trace, and none exists").
`practices/README.md` lists handing over as holding no practice.
M10 covers only handing understanding and decisions to a human.
So the answer is agent-to-agent or session-to-session handover. The question's premise that a whole moment has nothing at all does not match the text.
