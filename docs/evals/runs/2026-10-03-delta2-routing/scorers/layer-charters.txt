Key:
In order, stopping at the first yes: is it in force regardless of situation (axiom); does following it produce a result of its own (method); does it govern how an artifact is written - its form, whatever the work was (style); does it leave a trace in the record of the work that a check could test (rule); otherwise practice.

2 for all five steps in this order with these tests. 1 for an order or tests that would still file M1 as a method, M3, M4, M5 and K2 as rules, and M6 as a practice; or four of the five steps. 0 otherwise.

--- answer a-2cf3e5bb ---
From M0 (methods/README.md, "Placement"), cited by RU0 and PC0. Ask in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? -> axiom (`axioms/`).
2. Does following it produce a result of its own (a verdict, an artifact, a record)? -> method/procedure (`methods/`). Guidance that only requires a record to carry something is a rule.
3. Does it govern how an artifact is written, its form whatever the work was? -> style (`style/`).
4. Does it leave a trace in the record of the work that a check could test? -> rule (`rules/`).
5. Otherwise -> practice (`practices/`).
