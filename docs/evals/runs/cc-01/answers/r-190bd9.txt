### OBSERVATIONS
- `work-types/README.md` "Gaps recorded" has two adjacent sentences that contradict each other: "The domains set has not said which, and its answer settles this." and then "The domains charter's tie-break, applied to one such change, settles which."
- `work-types/README.md` describes the Build group as changing "the organisation's own machinery and knowledge". Yet every Build work-type (W1, W2, W3, W5) excludes knowledge-methodology in its frontmatter, as W0's own gap note admits.
- `artifacts/README.md` line 13 says each document type comes "each with a schema". This conflicts with `schemas/README.md`, which says lifecycle documents have no contract and only prose templates, and with AR1 and AR6, which ship no template at all.
- The root `README.md` layer table lists `docs/` ("This corpus's own artifact instances"), but no `docs/` directory exists in this corpus copy. So check-board.mjs has nothing to check here.
- E3 and E4 cite "thirteen charters". The current INDEX lists 16 layer charters (`<prefix>0`). This reads as history but is not marked as point-in-time.
- V3 wording: RU0 says "no rule entry", which is not the same as "no rule applies", because standing-context guidance with a trace applies at Verifying.
