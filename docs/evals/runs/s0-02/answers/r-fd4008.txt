### layer-charters.H5
A rule must declare `trace` in its frontmatter: "the observable in the record that shows it was kept or broken, required by the catalogue contract" (rules/README.md "Member shape").
The schema enforces this. catalog-entry.schema.json has an if/then: when category is `rule` and the id matches `^RU[1-9][0-9]*$`, `trace` is required, with a minimum length of 20.
A practice "declares no `trace`; if it acquires one, it is a rule and moves" (practices/README.md).
A rule may optionally name a tool in `enforced-by` (pattern `^tools/`) "when a tool checks it". `tools/check-enforcers.sh` checks that the named tool exists, and "a rule with no tool yet is still a rule, and is checked by reading the trace" (rules/README.md).
The schema's own `trace` description agrees: "Naming a tool that checks it is enforced-by's job, and is optional."

### layer-charters.H6
methods/README.md "Placement" says to ask in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? If yes, it is an axiom (`axioms/`).
2. Does following it produce a result of its own (a verdict, an artifact, a record)? If yes, it is a method (`methods/`). Guidance that only requires a record to carry something is a rule, not a method.
3. Does it govern how an artifact is written, its form whatever the work was? If yes, it is style (`style/`).
4. Does it leave a trace in the record of the work that a check could test? If yes, it is a rule (`rules/`).
5. Otherwise, it is a practice (`practices/`).
rules/README.md and practices/README.md both restate this order: "axiom, procedure, style, rule, practice".

- methods/README.md says procedures "sit at five of the six" moments but does not name the missing one. By its table, the missing moment is *deciding what to keep*, which is held entirely by rules (RU1, RU3).

- In methods/README.md, the `---` before "## Faults" comes directly after a prose line with no blank line. In Markdown, that can render the preceding line as a setext heading instead of a horizontal rule.

- PC1 is placed at *Entering* ("how to begin in an unfamiliar collection"), but its hydrate-when is "about to add an entry to a curated collection". This fits, but entering a collection and adding to one are slightly different framings.
