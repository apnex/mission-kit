### layer-charters.H5
A rule must declare `trace` in frontmatter: "the observable in the record that shows it was kept or broken, required by the catalogue contract" (rules/README.md, Member shape). The schema enforces this: schemas/catalog-entry/v1alpha1/catalog-entry.schema.json makes `trace` required when category is `rule` and id matches `^RU[1-9][0-9]*$`, with minLength 20.
A practice "declares no `trace`; if it acquires one, it is a rule and moves" (practices/README.md).
Optionally, a rule may name `enforced-by` (a path matching `^tools/`) when a tool checks it. `tools/check-enforcers.sh` then holds that tool to existing. "A rule with no tool yet is still a rule, and is checked by reading the trace" (rules/README.md). The schema's `trace` description agrees: "Naming a tool that checks it is enforced-by's job, and is optional."

### layer-charters.H6
methods/README.md (M0), "Placement", says to ask in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? Then it is an axiom (axioms/).
2. Does following it produce a result of its own (a verdict, an artifact, a record)? Then it is a procedure/method (methods/). Guidance that only requires a record to carry something is a rule.
3. Does it govern how an artifact is written, its form, whatever the work was? Then it is style (style/).
4. Does it leave a trace in the record of the work that a check could test? Then it is a rule (rules/).
5. Otherwise it is a practice (practices/).
rules/README.md, practices/README.md and style/README.md all cite this as "axiom, procedure, style, rule, practice, asked in that order."

### layer-charters.H7
The gap is handing over: specifically, handing work in progress to another agent or to a later session.
methods/README.md: "*Handing over* holds `M10`, which hands understanding and decisions to a human; handing work in progress to another agent or a later session has no procedure at all."
rules/README.md: *handing over* holds no rule today ("A rule for handing over - *a handover record names what is unfinished* - would leave a trace, and none exists").
practices/README.md: "*Verifying*, *deciding what to keep* and *handing over* hold no practice today."
This is the only moment that all three layers list as a gap, and M0 adds that it "applies to an agent working alone as much as to many: a lone agent hands over to its own next session."
One qualification: at the level of whole moments, *handing over* is not entirely empty, because M10 covers handover to a human. The truly ungoverned part is agent-to-agent and session-to-session handover.

- M0 says "procedures sit at five of the six" moments. The table confirms this: deciding what to keep has no method. RU0 lists entering, committing, verifying and handing over as rule gaps.
- The style grain table has no row that obviously fits a heading-case rule.
