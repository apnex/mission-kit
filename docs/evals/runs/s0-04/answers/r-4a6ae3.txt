### layer-charters.H5
A rule must declare `trace` in frontmatter: "the observable in the record that shows it was kept or broken, required by the catalogue contract" (`rules/README.md`, "Member shape").
The schema enforces this for any RU1+ entry (`schemas/catalog-entry/v1alpha1/catalog-entry.schema.json`: if category is `rule` and the id matches `^RU[1-9]`, then `trace` is required).
A rule may optionally name `enforced-by`, the tool that checks it. `tools/check-enforcers.sh` holds that tool to existing, and "a rule with no tool yet is still a rule, and is checked by reading the trace". The schema's `trace` description says naming a tool "is optional".
A practice "declares no `trace`; if it acquires one, it is a rule and moves" (`practices/README.md`).

### layer-charters.H6
The order comes from `methods/README.md` (M0), "Placement". Ask in order and stop at the first yes:
1. Is it a limit a system is built toward, in force for every system with the traits it names? If yes, it is an axiom.
2. Does following it produce a result of its own (a verdict, an artifact, a record)? If yes, it is a method. Guidance that only requires a record to carry something is a rule, not a method.
3. Does it govern how an artifact is written, its form, whatever the work was? If yes, it is style.
4. Does it leave a trace in the record of the work that a check could test? If yes, it is a rule.
5. Otherwise, it is a practice.
`rules/README.md` and `practices/README.md` both restate the same order: "axiom, procedure, style, rule, practice".

### layer-charters.H7
The gap is handing work in progress to another agent or to a later session, inside the "handing over" moment.
`methods/README.md` says: "handing work in progress to another agent or a later session has no procedure at all". `rules/README.md` says handing over holds no rule, and "A rule for handing over - *a handover record names what is unfinished* - would leave a trace, and none exists". `practices/README.md` lists "handing over" as holding no practice.
The only member of that moment is M10, which hands understanding and decisions to a human, not work to an agent.
M0 explains why this matters: "Every reader of this corpus starts cold, so handover is the moment that condition bites hardest". This includes "a lone agent [that] hands over to its own next session".
Strictly, no whole moment is empty, because M10 sits at handing over. The ungoverned part is agent-to-agent or session-to-session handover.
