## Correction - the rule offered to the director

**Banner.**\
The message recommending A said: split a product only where the proof of work differs in kind, and under that rule the machinery's code goes in its own domain.\
That composition was false: the machinery's code and its state also differ in kind, so that rule would have split them, just as it splits the product's code from its records.\
The rule written into `D0` adds the condition that makes A follow - *and the split has been found needed* - which is the set's existing grow-on-a-gap principle.\
Readers noticed the same seam: the answer to why the machinery is not split rests on history, not on a difference in principle.
