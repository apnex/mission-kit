## Correction - territory claims scope, not holdings

**Banner.**\
The first revision removed *doc, commit, and naming conventions* as a false claim, because no member governed commits or naming.\
The director ruled otherwise: the set **should** cover commit and naming conventions, and code comments too, and a missing member does not invalidate the claim - **that is how gaps are found.**\
The removal reasoned from holdings to scope, which is backwards: narrowing the claim to fit the population erases exactly the gaps a territory exists to expose.

**Applied.**\
Territory now claims every medium a reader meets and partitions by medium, then grain; commit messages, code names and code comments are rows with no member.

**Measured.**\
Run `s0-03`, `s0` only: before 12.67 / 14, after **14 / 14**.\
Run `s0-04`, the two standing suites whose probes touch style (`layer-charters`, `explain-routing`): before 25.67 / 26, after **26 / 26**, no regressions.\
`work-layers` and `system-boundary` were not re-run on this revision; a keyword search of their keys for *style, commit, naming, comment, medium* matched only `work-layers.L6`, on methods against skills, which this change does not touch.

**Open.**\
`E4` says a territory is derived from the population; it does not say that the extent of the claim is set by purpose.\
Whether to state that in `E4`, and recheck the six charters already applied against it, is put to the director.
