## The ruling, as applied to `E4`

- **A charter holds the set's vision, and manages the set against it.** The vision - what the set is for and claims to cover - is never cut to fit current holdings. The rest is management: territory, boundaries, faults, and changes.
- **The territory obligation is split.** The partition is derived from the population; its extent is set by purpose. A cell no member fills is kept and named as a gap.
