## The ruling

- **A vision** is the engineered statement of an ideal end state; `AR6` says how one is written.
- **A set** is a population whose members need not know each other or how they are governed.
- **A charter** is the one place that answers what the set is, what it covers, and how it is governed: a **vision half** - `AR6`'s devices applied to the set - and an **operating half** - how the set is analysed, balanced and changed.

## Addendum - operating the charter, and operating the set

**Ruling.**\
Operating a charter - changing its text - is distinct from operating the set it governs - changing its population.\
The frame as first built said each set was "changed by `M11`", which changes the charter; nothing covered admitting, modifying, retiring or rebalancing a member.

**Applied.**
- `M13` **new**, change a set's membership: admit (scope, admission tests, growth policy, author from a peer, a new id, the required frontmatter and sections, index, gate), modify (keep the id; test by `M2` if a reader's decision changes), retire (delete with no stub, disposition, `supersedes` on a successor, live citations repaired and frozen records left, the id retired for good), rebalance (from a backlog row, weighed on the board, selected by the director; the charter changes first by `M11` only if it is itself wrong). It gathers steps that were scattered across the charters, `PC1`, the root README, `SC6` and `W3`, and cites the runs it describes.
- Every Operation section now reads: analysed by `M12`, membership changed by `M13`, charter changed by `M11`. `E4` states the two are kept apart.
- `M11`'s line on replacing a member in a capped set corrected under a banner; `M12` routes findings about members to `M13`.

**Measured.**
