## 1. The ruling

A boundary separates two units only where it is declared and honoured.\
A unit reaching past a declared interface stays one system with it for what a change answers to.\
A detected bypass is a signal as well as a fault: the interface is evaluated against the component's duty and vision, ending in the consumer being rerouted or the interface adjusted.
